# internal/server/router

В этом пакете размещается настройка маршрутов HTTP-сервера.

Роутер связывает URL и HTTP-методы с методами контроллеров.

В текущей структуре роутер:
- не содержит бизнес-логики
- не работает напрямую с репозиторием
- только мапит входящие запросы на соответствующие методы контроллера

Это позволяет держать маршрутизацию отдельно от HTTP-обработки и бизнес-логики.
