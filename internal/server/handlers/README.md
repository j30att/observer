# internal/server/handler

В этом пакете размещаются команды приложения.

Команда инкапсулирует одно действие бизнес-логики и обычно имеет метод `Execute(...)`.

В текущей структуре команды:
- принимают входные данные от контроллера
- выполняют бизнес-логику
- обращаются к репозиторию для сохранения или чтения данных

Такой слой помогает отделить HTTP-логику от логики приложения.
